Native studs keep the lawn legible.

Remaining / deliberately separate

Dense Crocodilo overlap and distant or oblique name readability remain bounded visual concerns. Evaluate them at real gameplay cameras before changing model scale, text depth or spacing.

Rainbow Lucky colors are documented without adding a rarity or economy rule. Existing scenery should be compared before adding more geometry. Nests remain excluded.
