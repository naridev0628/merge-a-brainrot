# Revised research organization

Use the six numbered notes for the new game. The master build prompt is canonical; these notes record evidence, calculations and review methods.

`SOURCE_INVENTORY.csv` distinguishes checked official documentation, user recollections, original design and research gaps. `ORIGINAL_RESEARCH_INVENTORY.csv` inventories all 1,776 source members without claiming they are current Chicken Farm facts. `ORIGINAL_PROMPT_SECTION_INVENTORY.csv` makes the old prompt structure traceable.

`generated/ORIGINAL_ECONOMY_SPEC.json` is a portable design-data appendix containing the original six-tier catalog and limits. It is not a Roblox implementation. The archived generators and competitor catalogs are not copied or run.

When adding research, record source/date/version and the exact supported observation. Keep uncertain values uncertain. Direct normal-play observations should carry a timestamp and source identity; a video transcript or community article is not a substitute for a measured mechanic. Do not import irrelevant biome, combat, premium-product or decompiled configuration merely because it appears in the legacy research.

Legacy originals remain in the user's Downloads folder. The replacement archive ships newly authored notes and inventories only.
