# Chicken Farm and evidence ledger

Checked 2026-10-14. Confirmed by the user: **Chicken Farm by Skandi Studios**, Roblox place **137233438285284**. [Official experience page](https://www.roblox.com/games/137233438285284/Chicken-Farm).

Its public description supports buying chickens, converting eggs to cash, merging into rarer chickens and a nest-building theme. It also mentions rebirth updates and laying while away. That supports the broad inspiration; it does not publish an exact two-input recipe, complete tier table, prices, intervals, rebirth thresholds or reset rules. Offline production is deliberately outside this project's v1.

**Steal a Brainrot**, by BRAZILIAN SPYDER, describes buying/stealing characters, earning money and rebirth. It is a character-collection genre reference. Its public page grants no model reuse permission. [Official experience page](https://www.roblox.com/games/109983668079237/Steal-a-Brainrot).

The supplied six research reports primarily document Steal An Egg. They contain no verified Chicken Farm loop research. Exact competitor values and current popularity claims are not imported. No live play session in either reference experience was conducted for this package.

## Evidence classes

| Class | Meaning | Project use |
|---|---|---|
| `verified_primary` | Public official page/documentation inspected on the recorded date | Claim limited to what that source actually publishes |
| `user_reported` | The user's recollection/described play experience | Design motivation; not a measured competitor value |
| `original_design` | Rules and numbers selected for this new game | Canonical v1 implementation inputs |
| `legacy_archive` | Original filename/content inspected in the supplied ZIP | Historical context; no current-game or license assumption |
| `needs_observation` | Capture/timing/recipe not yet checked live | A research task, not an empty slot to fill with guesses |

`SOURCE_INVENTORY.csv` holds the current ledger. `ORIGINAL_RESEARCH_INVENTORY.csv` holds every historical file. Sources can support a broad feature without establishing its detailed implementation.

## Observation plan for future Chicken Farm research

Use a normal permitted gameplay session and record the date/version, account state and URL. Observe one buy → produce → collect → sell → merge cycle. Record the on-screen recipe rather than assuming the project recipe equals the competitor recipe. Time the first production, collection, sale and merge; distinguish narrated claims from directly visible events. Record rebirth requirement and reset wording only if actually reached. Capture UI readability and interaction patterns, not game files or proprietary models.

Fill `reference/PLANNED_CAPTURE_INVENTORY.csv` with a capture filename, URL, timestamp, observer, lesson and rights status when evidence exists. A proposed capture is labelled `not_captured`; the package does not substitute unrelated Steal An Egg screenshots.

Unresolved: exact Chicken Farm merge count, intervals, capacity, tier progression, rebirth reset contents, mobile controls and current balance. These are not blockers for an original prototype, because this prompt explicitly chooses its own rules. No market-growth or revenue forecast has been verified.
