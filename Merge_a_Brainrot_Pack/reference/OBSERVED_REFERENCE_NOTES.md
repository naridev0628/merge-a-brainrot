## Disposition and limits

Every listed image remains reference-only, with production and redistribution permission unverified. The original ZIP stays with its owner as source evidence; this package distributes newly written descriptions, paths and inventories. Numerical asset IDs embedded in other filenames are historical strings and must not be inserted into the new experience.

These files do not establish Chicken Farm's merge count, tier list, intervals, caps, rebirth reset contents or mobile interaction. The public experience page supports broad inspiration; future normal gameplay observations can be logged in `PLANNED_CAPTURE_INVENTORY.csv`. The requested two-input recipe and all new economy values remain explicit project choices.

Legacy guardians, biomes, treadmills, speed, PvP gear, mutations, random purchases, admin events and secret spawns stay outside the new MVP. Their presence in a reference folder does not create an implementation requirement.
