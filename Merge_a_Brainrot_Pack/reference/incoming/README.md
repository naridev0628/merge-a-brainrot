# Incoming reference evidence

This folder is reserved for future evidence supplied by the owners. No competitor media is redistributed here. Keep the original ZIP downloads as the source archive; their member paths and hashes are already recorded in `../ORIGINAL_REFERENCE_INVENTORY.csv`.

For a new file, record its original name/path, source URL when known, creator, capture date, hash, who supplied it, intended use and permission evidence. Preserve the source path even if a clearer local display name is added. Unknown dates or rights stay blank/`needs_review`; do not fill them from guesswork or label an uploaded image “licensed.”

Use screenshots and clips to write a dated observation and an original adaptation. Keep borrowed imagery separate from production assets and public packages. A normal gameplay capture is not permission to extract a place, mesh, script, texture or recording. Do not execute supplied code or connect it to Studio merely to inspect it.

When matching an incoming file to `../PLANNED_CAPTURE_INVENTORY.csv`, change `capture_status` only after the actual capture exists. Fill the recorded path/date/observer/build/account state and the observed result. A filename in `proposed_path` is a plan, not evidence.

Actual production asset requests are reviewed in `../../assets/ASSET_MANIFEST.csv`. Store approval/provenance evidence there separately; this incoming folder is not an approval register.
